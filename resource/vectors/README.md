# Vectors

`play_arrow`, `pause`, `skip_previous`, `skip_next`, `volume_up`, and `volume_down` are Material
Symbols (Rounded, filled), downloaded from https://fonts.google.com/icons and re-wrapped with a
positive viewBox. They are © Google and licensed under the Apache License 2.0
(https://github.com/google/material-design-icons/blob/master/LICENSE), the same license as this
app. The other files are this app's own 24-point stroke glyphs.
